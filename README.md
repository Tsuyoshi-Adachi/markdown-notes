# Markdown公開テスト

このページは、Markdown文書の作成・更新と公開表示を確認するためのサンプルです。

## 見出しと書式

**太字**と通常の文章を表示します。

- 1つ目の項目
- 2つ目の項目

## 表

| 操作 | 方法 |
| --- | --- |
| ChatGPTによる作成・更新 | この文書を直接保存します |
| 所有者による編集 | 鉛筆ボタンから編集し、Commit changesで保存します |
| 公開閲覧 | このページのURLを開きます |

## 数式

各項を $x_i$ とすると、合計は次のように書けます。

$$
\sum_{i=1}^{n} x_i = 1
$$
